# Корици в BookBuddy

Полето „Търси книга по заглавие или автор“ във формата за добавяне и редакция предлага записи от Google Books и Open Library. Изборът попълва заглавие, автор, ISBN и брой страници, когато доставчикът ги предоставя. Полетата остават достъпни за ръчна редакция. „Премахни избраната корица“ изчиства избрания URL. Промяната на ISBN също изчиства URL на предишното издание.

## Интерфейс на услугата

`src/services/coverService.js` дава глобален `CoverService` на класическите скриптове. Зарежда се след `src/utils/validate.js`.

| Метод | Резултат |
|---|---|
| `search(query, { limit = 8 })` | Promise с масив от `id`, `title`, `authors`, `coverUrl`, `source` и наличните `year`, `isbn13`, `isbn10`, `pageCount`. |
| `searchWithStatus(query, options)` | Същите резултати и `available`, за да различава интерфейсът празен резултат от недостъпна услуга. |
| `resolveCover({ isbn, title, author })` | Promise с `{ url, source }`. При липса на съвпадаща корица и двете полета са `null`. |

Google Books е първият източник. Ако няма подходяща корица или заявката е неуспешна, услугата пробва Open Library. Търсенето ползва `search.json`, а проверката на корицата ползва идентификатор на изображение или валиден ISBN с `?default=false`. Това позволява липсващо изображение да се различи от успешен отговор.

След запис приложението зарежда избрания `coverUrl`, след него корица от Open Library по ISBN, а докато чака или при грешка показва местната типографска корица. Изображенията се зареждат отложено, без HTTP referrer, в запазено поле 2:3. Service worker кешира само файловете на приложението.

Запазеният URL е незадължителен. Нормализира се до HTTPS и се приемат само `books.google.com`, `books.googleusercontent.com`, `covers.openlibrary.org`, `archive.org` и техни поддомейни. Заявките за търсене изпращат само заглавие, автор или ISBN.

## Кеш и ключ

- Търсенето във формата изчаква 300 ms след въвеждане. Еднакви едновременни заявки споделят резултат. Заявките имат 6-секунден таймаут и един повторен опит при HTTP 429 или 5xx.
- Кешът `bookbuddy_cover_cache` в `localStorage` пази най-много 200 резултата за 30 дни. Повредени записи се пропускат, а при проблем със записа търсенето продължава.
- По желание може да се зададе `window.BOOKBUDDY_CONFIG.googleBooksKey` преди зареждане на услугата. Всеки ключ в браузъра е публично видим. Ограничава се до Google Books API и разрешените HTTP referrer-и. Ключът не се съхранява в репото.
- Без ключ Google Books може да върне 429 дори при малък трафик. Покритието на българските заглавия и издания варира. При няколко издания със същото заглавие авторът и ISBN помагат да избереш правилното.

## Проверки

```sh
node readme-ai-project/tests/coverService.test.mjs
node readme-ai-project/tests/live-probe.mjs
```

Втората команда е ръчна. Тя изпраща 20 публични заглавия и проверява дали кандидатът за корица отговаря с изображение. При квота или липса на достъп до доставчика интерфейсът може да се провери чрез Chrome DevTools с подменени JSON отговори за двата API адреса и с JPEG за заявката за корицата. Кадрите на формата са от такава проверка.

[Google Books API](https://developers.google.com/books/docs/v1/using) · [Open Library Search API](https://openlibrary.org/dev/docs/api/search) · [Open Library Covers API](https://openlibrary.org/dev/docs/api/covers)
